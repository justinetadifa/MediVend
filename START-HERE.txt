MEDIVEND — PHP / MYSQL CATALOG DEMO

RUN WITH XAMPP
1. Keep this project in C:\xampp\htdocs\MediVend.
2. Start Apache and MySQL in the XAMPP Control Panel.
3. Use the existing medivend_db database. On a fresh installation, import your
   original medivend_db.sql using http://localhost/phpmyadmin/.
4. Check config/database.php:
   host: localhost | port: 3306 | database: medivend_db
   username: root | password: empty
5. Open http://localhost/MediVend/ and tap “Get Started”.

Do not open index.html directly or use a static-only live server for ordering.
The catalog needs PHP running through Apache. There is no build or npm install.
The existing database schema and original SQL file are unchanged.

CATALOG AND PRICES
- api/products.php reads active rows from products (is_active = 1).
- Product names, descriptions, prices, and quantities come from MySQL.
- price_centavos is an integer: 500 = PHP 5.00, 1000 = PHP 10.00.
- stock_quantity supplies each item's cart limit; zero stock disables adding.
- image_path is a local web path such as assets/my-product.png.
- Null/empty or broken images use a bundled photo or local placeholder.
- Loading, empty catalog, and connection failure have separate visible states.
- “Try again” / “Refresh catalog” retries the request.
- Start over or a page reload gets a fresh catalog and clears the session.

WHAT IS PRESERVED
- Centered welcome screen and continuously moving medicine photos.
- MediVend branding, Poppins/Inter fonts, green buttons, and black outlines.
- Touch feedback, screen transitions, cart effects, and local images.
- Add, increase/decrease, remove, computed totals, and checkout review.
- Empty-cart checkout prevention and demo acknowledgement.

SIMULATION BOUNDARIES
Only the catalog is connected to the database. Completing a demo order does
not write transactions, take payment, reserve/decrement stock, or dispense
medicine. The cart and demo order remain in browser memory; reloading clears
them. Medicine use still requires clinic guidance.

QUICK CHECK
1. Open http://localhost/MediVend/api/products.php and inspect the JSON.
2. In the supplied sample data, two Paracetamol items total PHP 10.00.
   Adding one Cetirizine brings the total to PHP 18.00.
3. Add up to the stock limit, decrease quantity, remove, and review your order.
4. Stop MySQL temporarily to view the connection-error state; restart it and
   tap “Try again”. No active products produces the empty-catalog state.
5. In PowerShell from this project directory, run the read-only API checks:
   & 'C:\xampp\php\php.exe' tests/products-api.test.php

ON A 7-INCH TOUCHSCREEN
Use 1024 x 600 landscape with 100% display scaling and browser zoom.
Connect the screen's TOUCH port by USB and move the browser to that display.
Press F11 for full screen. MySQL and Apache must keep running.
