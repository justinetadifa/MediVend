# MediVend touchscreen starter

Open **START-HERE.txt** for setup and project boundaries. Extract the folder,
then open `index.html` directly or serve it through XAMPP Apache.

Plain HTML, CSS and JavaScript. No install, build, database, or internet required.
Designed for a 1024 × 600 landscape touchscreen, with responsive fallbacks.

The project is an offline interactive demo featuring Diatabs, Biogesic, and
Cetirizine at ₱10 each, with local product photos, cart editing, and a simulated
checkout. It contains no production payment or hardware integration.
All product and price data is illustrative.

The welcome screen uses bundled Poppins and Inter fonts, with a seamless
right-to-left medicine photo loop. Tap **Get Started** to select medicines;
**Start over** clears the session. Reduced-motion preferences are supported.
